# Sistema de Gestión de Tareas

Aplicación web desarrollada con TypeScript, HTML y CSS que permite organizar actividades personales mediante un sistema de gestión de tareas.

## Descripción

El proyecto permite registrar, administrar y organizar tareas de manera sencilla. Los datos se almacenan en el navegador mediante LocalStorage, por lo que permanecen guardados aunque se cierre o actualice la página.

## Tecnologías utilizadas

- TypeScript
- HTML5
- CSS3
- Vite
- LocalStorage
- Git y GitHub

## Funcionalidades

- Registrar nuevas tareas.
- Editar tareas existentes.
- Eliminar tareas.
- Marcar tareas como completadas o pendientes.
- Asignar categorías.
- Establecer prioridades: baja, media y alta.
- Buscar tareas por título.
- Filtrar tareas por estado.
- Filtrar tareas por prioridad.
- Guardar información automáticamente en LocalStorage.


## Instalación y ejecución

### Requisitos previos

- Node.js
- npm
- Git 

### 1. Clonar el repositorio

```bash
git clone https://github.com/3smer4ld4/sistema-organizacion
```

### 2. Entrar en la carpeta

```bash
cd sistema-organizacion
```

### 3. Instalar dependencias

```bash
npm install
```

### 4. Ejecutar el servidor de desarrollo

```bash
npm run dev
```

Vite mostrará una dirección local para abrir la aplicación en el navegador.

## Almacenamiento de datos

La aplicación utiliza LocalStorage del navegador para conservar las tareas registradas. Los datos se guardan localmente y no requieren una base de datos externa.
